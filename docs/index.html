Measurement choices changed the story.

When evaluated strictly against human-verified dense references and multi-center clinical cohorts, three widespread assumptions in cell detection literature fail to hold.

Field Overlap Leakage

Filenames were insufficient for independence.

Automated feature matching and photometric verification revealed 791 overlapping microscope field pairs. A standard filename-grouped split would have allowed 10 of the 20 dense evaluation fields to cross partition boundaries, severely inflating apparent generalization.

10 / 20 Evaluation fields leaked under filename splits
Reference Completeness

Sparse labels distorted both precision and recall.

On identical model predictions across the 20 evaluation fields, abnormal precision reached 52.4–87.1% against the dense reference, but plummeted to 20.4–45.7% against sparse annotations because unannotated cells were erroneously penalized as false positives.

52.4% vs 20.4% Measured precision shift from sparse reference penalty
Cross-Center Generalization

Cross-center transfer remained weak.

On external HMCHH slides, detectors recalled 20.8–51.8% of annotated abnormal cells. Reference-matched precision ranged between 3.8% and 6.7%, highlighting dramatic domain shift arising from institutional staining and slide preparation protocols.

3.8% – 6.7% Reference-matched abnormal precision on HMCHH

Methodological Progress & Core Empirical Inferences

How auditing the initial baseline exposed latent dataset leakage and sparse reference penalties, and the resulting four scientific inferences that redefine how cervical cytopathology object detectors must be validated.

Milestone 01 · Data Split Leakage

From Filename Splitting to Connected-Component Partitions

Initial cytology baselines split images at random by filename, assuming distinct filenames represented distinct specimens. Cross-correlation analysis revealed 791 heavily overlapping field pairs (≥ 0.90 normalized cross-correlation), causing 10 out of 20 evaluation fields to leak into training.

Before (Baseline Flaw) Naive 80/20 filename split leaked identical cell clusters across train and test sets, inflating apparent validation accuracy.
After (Rigorous Protocol) Graph connected-component partitioning grouped all overlapping fields into strict disjoint components before any split.
Milestone 02 · Ground-Truth Reference

From Sparse Benchmark Penalties to 1,067-Cell Dense Human Attestation

Standard benchmark annotations labeled only 1–3 salient cells per field. Model predictions for unannotated true squamous cells were penalized as false positives, distorting baseline precision down to 20.4–45.7%.

Before (Sparse Artifact) Evaluating against sparse ground truth produced an artificial 20.4% precision ceiling due to unannotated true cells.
After (Dense Attestation) Label Studio re-annotation of 40 evaluation fields (1,067 cells: 706 normal, 361 abnormal) restored true precision to 52.4–87.1%.
Milestone 03 · Threshold Optimization

From In-Sample Peeking to Decoupled Operating Thresholds

Prior workflows peeked at test set precision-recall curves to report optimal confidence thresholds. We decoupled the protocol: confidence thresholds are tuned strictly on 20 development fields and frozen before evaluating test sets.

Before (In-Sample Peeking) Post-hoc threshold hunting on test fields generated overly optimistic precision-recall operating points.
After (Frozen Decoupled) Operating threshold frozen at 0.08 on 20 dev fields; tested blindly against 20 reserved fields and 1,077 external HMCHH fields.
Milestone 04 · Artifact Integrity

From Vulnerable Checkpoints to Cryptographic Integrity Vault

Raw PyTorch checkpoints posed remote code execution (RCE) deserialization risks and silent weight degradation. We implemented automated SHA-256 seal verification, strict torch.serialization checks, and git LFS tracking.

Before (Unverified Serialization) Vulnerable pickle loading, untracked large weights at risk of silent loss or truncation during repo transfers.
After (Audited Model Vault) 9 verified weights tracked in publication vault, verified via automated verify_weights.py SHA-256 integrity suite.

Four Empirical Inferences for Cervical Cytopathology AI

Key scientific takeaways establishing empirical realities of deep learning object detectors in automated cervical smear screening.

Inference 01 · Annotation Completeness

High Benchmark Precision is Frequently an Artifact of Incomplete Labels

"When reference annotations are incomplete, standard object detection metrics evaluate false negative annotations as false positive predictions."

Our multi-seed experiments prove that evaluating detectors against native sparse annotations causes up to a 50 percentage point collapse in apparent abnormal precision (52.4% vs 20.4%). Academic claims of poor precision in published literature often reflect benchmark ground-truth incompleteness rather than model failure.

Inference 02 · Domain Shift

Co-Training Heterogeneous Datasets Does Not Resolve Cross-Center Shift

"Pooling multi-source training data improves intra-domain diversity but fails to bridge clinical preparation divergence across centers."

Adding APCData to SIPaKMeD training sets yielded modest intra-domain gains, but external evaluation on 1,077 HMCHH slides revealed severely impaired generalization: abnormal recall remained between 20.8% and 51.8%, while reference-matched precision collapsed to 3.8%–6.7%. Institutional staining variance remains the primary deployment bottleneck.

Inference 03 · Spatial Overlap

Digital Microscopy Datasets Harbor Severe Latent Field Duplication

"Microscope field overlap invalidates random train-test splitting unless explicitly resolved through spatial correlation clustering."

In SIPaKMeD, 791 field pairs shared ≥ 90% normalized cross-correlation. Naive splitting placed identical cell clusters in both training and test sets. Rigorous spatial de-duplication is an absolute prerequisite for credible performance claims in digitized microscopy.

Inference 04 · Stain Normalization

Algorithmic Stain Transfer is Sensitive to Reference Slide Selection

"Stain normalization algorithms (Reinhard, Macenko, Vahadane) alter detector activations unpredictably depending on target reference choice."

Evaluating cross-center transfer under chromatic normalization showed that target reference selection introduces substantial variance in abnormal sensitivity. Uncalibrated color transfer cannot substitute for domain-adversarial representations or localized cytologist-in-the-loop screening.

The Clinical Translation Imperative

Autonomous diagnostic screening cannot rely on standard academic benchmark metrics without rigorous field deduplication, dense expert verification, and decoupled operating calibration. This research repository provides the full reproducibility codebase, audit tools, and certified weights to advance reproducible standards in digital cytopathology.
