# Targeted literature verification

Search date: 19 September 2026. This is a targeted primary-source check, not a systematic review or proof of novelty. No new datasets were added to the frozen experiment after this search.

Queries included `cervical cytology cross dataset object detection YOLO public datasets domain generalization`, `site.mdpi.com/2306-5354/13/3/289 "416" "91"`, `site.data.mendeley.com/datasets/ytd568rh3p "425"`, and `site.cs.uoi.gr/~marina/sipakmed "966"`. ## Defensible positioning

The project is a constrained, retrospective replication and measurement study. Its local value lies in transparently documenting annotation completeness, class alignment, source grouping, calibration and source-diversity effects with repeated seeds. Any future novelty statement would require a systematic, up-to-date search and a specific methodological contribution beyond implementing these established practices.

The 6 GB GPU limit describes the experimental resource budget; it does not establish a model-performance ceiling. Claims that normalization is unnecessary, that morphology invariance has been learned, or that public-only detection approaches must fall below a classification benchmark are not supported by this register.
